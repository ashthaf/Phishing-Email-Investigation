# Evidence

This directory contains all digital evidence collected during the investigation.

The integrity of all evidence must be preserved throughout the investigation.

## Structure

Chain-of-Custody/
Maintains evidence handling records.

Hashes/
Integrity verification hashes.

Original-Email/
Original email evidence exactly as received.

Working-Copy/
Copies used during analysis.

## Evidence Handling Rules

- Never modify original evidence.
- Always verify integrity using hashes.
- Perform all analysis using working copies.
- Record every action in the chain of custody.

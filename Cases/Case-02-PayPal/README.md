# CASE-02 – PayPal Gift Card Phishing Investigation

## Overview

This case documents the forensic investigation of a phishing email impersonating **PayPal** and promoting a fraudulent gift card campaign.

The investigation follows a structured incident response methodology covering:

- Evidence Preservation
- Initial Triage
- Header Analysis
- Mail Routing
- Authentication Analysis
- Sender Infrastructure
- Content Analysis
- URL Investigation
- IOC Extraction
- Threat Intelligence
- MITRE ATT&CK Mapping
- Risk Assessment
- Containment
- Incident Reporting

This case is part of the **Phishing Email Investigation & Incident Response Lab**.

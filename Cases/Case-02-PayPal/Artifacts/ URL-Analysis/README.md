# 📖 Overview

This directory contains the raw artifacts collected during the URL and domain investigation of the PayPal phishing email.

The artifacts were generated using standard Linux networking tools and were later validated using external Threat Intelligence platforms such as VirusTotal, Cisco Talos, URLScan.io, AbuseIPDB, MXToolbox, and WHOIS.

---

# 📂 Contents

| File | Description |
|------|-------------|
| extracted_urls.txt | URLs extracted from the phishing email |
| domains.txt | Domains extracted from the identified URLs |
| dig.txt | DNS lookup results using `dig` |
| whois.txt | WHOIS registration information |

---

# 🔬 Purpose

These artifacts support the following investigation phases:

- URL Analysis
- IOC Extraction
- Threat Intelligence
- Risk Assessment

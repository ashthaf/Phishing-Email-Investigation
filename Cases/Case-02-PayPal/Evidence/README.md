# 📖 Overview

This directory contains the primary forensic evidence collected during the investigation of the PayPal phishing email.

All evidence was preserved throughout the investigation to maintain integrity and support reproducibility. The collected evidence served as the foundation for every analysis phase, including header analysis, routing analysis, authentication verification, content analysis, URL investigation, IOC extraction, and Threat Intelligence validation.

---

# 🎯 Purpose

The evidence repository was created to:

- Preserve the original phishing email.
- Maintain evidence integrity.
- Record investigative notes.
- Document the chain of custody.
- Summarize all collected evidence.

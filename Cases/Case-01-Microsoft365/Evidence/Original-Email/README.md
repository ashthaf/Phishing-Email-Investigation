## ⚠️ Safety Warning

This repository is intended **solely for educational, defensive, and research purposes**.

The archived email is a **real phishing email sample** obtained from a publicly available phishing sample repository and was analyzed in an isolated laboratory environment.

Do **not** import, open, or interact with this email on a production system or a personal email account.

Always perform analysis inside an isolated virtual machine or sandbox environment.

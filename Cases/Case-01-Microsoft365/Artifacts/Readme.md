# Investigation Artifacts

## Overview

This directory contains forensic artifacts extracted during the investigation of **CASE-01 – Microsoft 365 Phishing Email**.

Artifacts were collected throughout the investigation from email headers, message content, routing information, and extracted indicators.

These artifacts form the basis for IOC extraction, threat intelligence enrichment, incident reporting, and future threat hunting activities.

---

## Artifact Inventory

| File | Description |
|------|-------------|
| domains.txt | Domains identified during the investigation. |
| email-addresses.txt | Email addresses extracted from the email. |
| filenames.txt | Names of evidence and extracted files. |
| ips.txt | IP addresses identified in the email routing. |
| message-ids.txt | Message-ID values extracted from the email header. |
| urls.txt | URLs extracted from the phishing email. |

---

## Purpose

The collected artifacts are used for:

- IOC Extraction
- Threat Intelligence
- MITRE ATT&CK Mapping
- Risk Assessment
- Detection Engineering
- Threat Hunting
- Incident Reporting

---

## Evidence Source

All artifacts were extracted directly from the preserved phishing email without modifying the original evidence.
